Assignments from the Programming Fundamentals course (2025.2 semester, Cesar School), from logical reasoning in Portugol to implementation in Python.

## About

The course starts with pseudocode in Portugol, a Portuguese-language teaching pseudocode, to build algorithmic reasoning, and then takes the same problems to Python. The semester ends with a CRUD in Python and SQLite.

## Contents

All folders live in `4 - Fundamenos de Programação - AEDA/`.

| Folder | Language | Content |
| --- | --- | --- |
| `Portugol/27-08-2025`, `Portugol/03-09-2025` | Portugol | Input and output, averages, conversions, decision structures, customer registration |
| `Ficha Da AV1` | Portugol | First exam exercise list: cash register, cinema box office, investment simulator, attendance control, fuel and paint consumption, among others |
| `Aula 1 Phyton.17_09_2025` | Python | First programs: BMI, average, temperature converter, trip cost, gas station, calculator |
| `Aula 2 Python.24_09_2025` | Python | Class material organized into basics, control flow, functions and scope, lists and exercises |
| `Aula 3 Phyton.01_10_2025`, `Aula 4 Python.29_10_2025` | Python | Loop and list exercises |
| `AulaDeDicionario_05_11` | Python | Dictionaries |
| `RevisãoPython`, `RevisãoPython2` | Python | Review lists for the exam |
| `CRUD` | Python + SQLite | Medical specialty registry with create, list, update and delete (`Especialidades.py`) |

## Topics practiced

- Variables, types and operators
- Decisions (`if`, `elif`, `else`) and loops (`for`, `while`)
- Functions, scope and modularization
- Lists and dictionaries
- Persistence with `sqlite3` and integrity error handling

## Running

Requirement: Python 3.

```bash
git clone https://github.com/Luisr-nunes/Fundamentos-de-Programa-o.git
cd "Fundamentos-de-Programa-o/4 - Fundamenos de Programação - AEDA"

python "Aula 1 Phyton.17_09_2025/CalculoIMC.py"
cd CRUD && python Especialidades.py
```

The `.por` files open in [Portugol Studio](https://univali-lite.github.io/Portugol-Studio/) or [Portugol Webstudio](https://portugol.dev/).
